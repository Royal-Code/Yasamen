# Patterns — Grupos

Grupos definem a taxonomia funcional dos patterns. Cada grupo contém patterns com responsabilidade semelhante dentro da composição de telas.

## Grupos

- **SHELL**: Shell patterns — definem o contêiner estrutural da experiência, a navegação global, o tipo de produto e a forma dominante de uso entre telas.
- **PAGE**: Page patterns — definem o arquétipo estrutural de uma tela, suas zonas obrigatórias, interação dominante e relação com shell e UI patterns.
- **UI-STRUCT**: UI patterns estruturais — organizam o espaço, regiões, painéis, colapso, scroll e composição sem carregar semântica de negócio própria.
- **UI-NAV**: UI patterns de navegação — organizam acesso, orientação, alternância, progressão e retorno entre destinos, vistas, etapas, seções ou níveis.
- **UI-DATA**: UI patterns de dados e listagem — representam coleções, itens, fluxos, hierarquias, agrupamentos e estruturas operacionais de dados.
- **UI-INPUT**: UI patterns de entrada — sustentam captura, edição, busca, filtros, seleção e parametrização de informações.
- **UI-ACTION**: UI patterns de ação — expõem comandos, operações globais, ações contextuais, ações prioritárias e execução rápida.
- **UI-FEEDBACK**: UI patterns de feedback e estado — comunicam ausência, progresso, falha, resultado, confirmação e bloqueios de estado.
- **UI-CONTENT**: UI patterns de conteúdo — organizam leitura, síntese, atributos, mídia, orientação contextual, comparação e conteúdo semântico ou documental.
- **UI-SURFACE**: UI patterns de superfície especializada — descrevem superfícies centrais com interação própria, como calendário, mapa, canvas, gráficos, viewer documental, câmera ou scanner.
- **UI-OVERLAY**: UI patterns de overlay e superfície temporária — descrevem superfícies sobrepostas, destacáveis ou temporárias, como sheet, drawer, popover, modal, painel flutuante e tooltip.
- **UI-INTERACTION**: UI patterns de interação e manipulação — descrevem gestos, seleção, foco, teclado, drag/drop, pan/zoom, reorder, resize e manipulação direta.
- **UI-SYSTEM**: UI patterns de sistema e host — descrevem capacidades da plataforma que afetam a tela, como permissões, lifecycle, offline/sync, tray, dock, janela, sessão e operações em background.
